# Eternal Embrace

A luxury, cinematic South Indian wedding invitation web application featuring gold temple architecture accents, smooth animations, RSVP management, event itineraries, and audio playback.

## Tech Stack

- **Framework**: TanStack Start & React 19
- **Routing**: TanStack Router
- **Styling**: Tailwind CSS & Lucide Icons
- **Animation**: GSAP & Lenis Smooth Scroll
- **State/Query**: TanStack Query
- **Deployment**: Nitro & Cloudflare / Node / Edge

## Getting Started

### Prerequisites

Node.js (v20+ recommended) and npm / bun.

### Installation

```sh
npm install
```

### Development

```sh
npm run dev
```

### Build

```sh
npm run build
```

### Preview

```sh
npm run preview
```
